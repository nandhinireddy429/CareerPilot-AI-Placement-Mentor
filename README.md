## 📖 Overview

**CareerPilot AI** is an AI-powered placement preparation platform designed to help students become placement-ready through personalized career guidance and intelligent AI features.

The platform combines **Large Language Models (LLMs)**, **Retrieval-Augmented Generation (RAG)**, **Semantic Search**, and **FastAPI** to provide an interactive experience for resume evaluation, interview preparation, coding practice, and learning roadmap generation.

Instead of using multiple websites for placements, CareerPilot AI brings everything together into one intelligent platform.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/CareerPilot-AI-Placement-Mentor.git
```

Navigate into the project

```bash
cd CareerPilot-AI-Placement-Mentor
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
OPENROUTER_API_KEY=your_api_key
```

Run the backend

```bash
uvicorn app:app --reload
```

Open your browser

```
http://localhost:8000
```
